ملف Excel

استخدم ملف Excel كقاعدة بيانات: استورد بياناتك أو صدّرها أو حمّل نموذجاً جاهزاً

ملاحظة مهمة: التعديلات التي تقوم بها هنا تُحفظ في متصفحك فقط (مسودة). حتى يراها الزوار، اضغط "نشر المنيو للجميع" ثم ارفع ملف menu-data.json على GitHub كشرح بالأسفل.

استيراد من Excel

اختر ملف Excel يحتوي على الأصناف. سيتم استبدال بيانات المنيو الحالية ببيانات الملف.

تصدير إلى Excel

يُنشئ ملف Excel بأحدث بيانات المنيو لديك (الأصناف + الأقسام).

نموذج جاهز للتحميل

ملف تجريبي يوضح الأعمدة المطلوبة لتعبئة بياناتك ثم استيرادها.

نشر المنيو للجميع

يُنشئ ملف البيانات المنشور (menu-data.json) بكل تعديلاتك الحالية لرفعه على GitHub فيظهر للجميع.

طريقة استخدام ملف Excel ونشر المنيو

  1. حمّل النموذج الجاهز وعبّئ الأعمدة: الاسم الوصف السعر القسم الصورة (رابط) متاح (نعم/لا)
  2. اضغط استيراد من Excel واختر الملف — ستظهر البيانات لك فوراً (مسودة).
  3. اضغط نشر المنيو للجميع لتنزيل ملف menu-data.json.
  4. افتح مستودعك على GitHub: Add file → Upload files وارفع الملف المحدّث ثم Commit changes.
  5. خلال ~دقيقة يعيد الموقع النشر ويرى الجميع المنيو الجديد.
